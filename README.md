# Type Garden

**Type to grow a beautiful animated garden.**

An interactive generative art experience. Every keystroke grows vines, roses, leaves, and tendrils. Space cuts stems, backspace makes letters wither, and enter clears the garden. Butterflies flutter in and perch on the flowers.

## Try it

Open `index.html` in a modern browser, or use GitHub Pages once enabled.

[Live demo (if Pages is enabled)](https://1048ae67-sudo.github.io/type-garden/)

## Controls

| Action | Effect |
|--------|--------|
| **Type** | Grow vines, roses, leaves around each letter |
| **Space** | Cut the previous word (new growth at the cut) |
| **Backspace** | Wither the last letter |
| **Enter** | Clear the entire garden |
| **Click / Tap** | Spawn a butterfly |
| **PNG / SVG** | Export the current garden |
| **Palette swatches** | Switch color themes |

## Features

- Procedural vine growth with thorns, leaves, roses, curls, and bridges between letters
- Multiple color palettes (Rose noir, Paper, Midnight, Citrus, Orchid, Moss, Tomato, Butter, Blush, Mono)
- Animated butterflies that fly in and perch on roses
- Responsive layout and mobile support
- Export as PNG or SVG
- Smooth spring physics and organic motion

## Technical notes

Pure HTML + Canvas + JavaScript. No build step, no dependencies beyond Google Fonts (Playfair Display + DM Mono).
